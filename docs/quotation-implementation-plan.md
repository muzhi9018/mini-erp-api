# 报价单功能设计与执行计划

报价以 SKU 为明细，从同一售价币种的商品组合中计算行金额和整单金额。新增、套用模板、从旧报价新建及修改已保存报价共用报价编辑页。未生成订单的报价可修改或删除，已生成订单的报价可查看，也可用来新建报价。本期记录转单状态，订单创建由后续项目实现。

## 1. 业务口径

| 事项 | 首版方案 |
| --- | --- |
| 报价资料 | 标题 `title` 默认「报价单」，报价时间 `quotedAt` 默认当前时间，两项可修改。客户名称、联系人、联系电话、收货地址、整单备注和每行备注按需填写。整单备注和每行备注在报价页直接填写，各最多 1024 字符。客户资料随正式报价保存。 |
| 报价选品 | 新建草稿的首行确定全单售价币种，清空商品行后可改选币种。新增或重新选择的 SKU 取当前参考售价，引用原报价的行取该行已保存的单价。已保存报价修改时沿用原币种。 |
| 正式单号 | 新建报价点击「保存报价单」并提交成功后取号。以 `Asia/Taipei` 的系统当天为取号日，人民币和新台币共用每日 `001` 至 `999`。修改已保存报价沿用原单号、编号日期和流水。手填报价时间用于业务展示。 |
| 优惠口径 | 「优惠折扣」以折数填写和显示，例如输入 `9.5`，控件带「折」后缀，成交额按原金额的 `0.95` 计算。「优惠后金额」在行级表示整行成交金额，在整单表示最终报价金额。 |
| 金额口径 | CNY、TWD 的结算金额均按两位小数计算。参考售价保留原有精度，金额沿用商品售价的税价口径。首版合计由行原价、行优惠和整单优惠构成。 |
| 模板内容 | 保存模板名称 `name`、报价标题 `title`、个人或公共范围、有序 SKU 明细、整单及行级折扣与备注。模板名称用于查找模板，报价标题用于报价表单和客户版。套用时每行默认数量为 `1`，价格实时读取。客户资料和固定优惠后金额由每次报价独立填写。 |
| 从旧报价新建 | 复制原报价的标题、报价时间、客户资料、备注、商品明细和两级优惠。用户可在复制前选择清理客户资料，在草稿中继续编辑，并在保存时取得新单号。 |
| 转单状态 | 新报价默认为「未生成订单」。已生成订单的报价锁定修改与删除，仍可查看客户版及作为新报价的来源。 |
| 客户版 | 在登录后的 ERP 内打开专用版式，操作名称为「预览客户版」或「查看客户版」。客户通过业务人员发送的截图查看。截图需要正式单号时先保存。 |
| 正式报价权限 | 报价列表、详情和客户版按创建人读取，修改、删除与复制同样校验归属。独立授予报价创建、查询、修改、删除和模板维护权限。 |

### 现有商品能力

- 复用 `IProductSkuService.options` 及其分页、关键字、类目和规格筛选。现有 `ProductOptionVO` 提供 `skuId`、所属商品、参考售价、`referenceSaleCurrency`、单位、`quantityScale`、`productVersion` 和 `skuVersion`。报价选品增加售价非空与指定币种条件，保留原选品入口的现有行为。
- 计量单位来自商品档案，数量小数位按 SKU 的 `quantityScale` 判定，范围为 0～6。即使两个 SKU 使用同一个计量单位，也可有不同数量精度。
- 正式保存新增或替换的商品行时，在同一事务调用 `IProductSnapshotService.getOrCreate(skuId, productVersion, skuVersion)`。保留或复制的商品行直接复用服务端查出的原快照 ID。商品快照冻结描述、规格、单位及其精度等资料，报价明细另存数量、单价、币种和计算结果。历史详情读取快照。 [商品接口联调说明](product-api.md#6-快照与后续单据)

## 2. 报价计算与交互

1. 选品查询只显示已启用、未删除且已维护参考售价和合法售价币种的商品与 SKU。查询按草稿已选币种或待修改报价的原币种过滤。进入客户版预览或正式保存时至少有一行，两者都在服务端校验全单币种。售价为 `0` 是有效价格，零库存 SKU 仍可报价。
2. 数量必须大于 0，最多 14 位整数，小数部分去掉末尾零后不得超过对应 SKU 的精度。例如精度为 0 时 `2.00` 合法、`2.50` 无效，精度为 2 时 `1.250` 合法、`1.251` 无效。数量超出精度时提示该行，计算过程保留原始数量。允许同一 SKU 重复出现在不同报价行，以便分别填写备注和优惠。
3. 每一行和整单分别选择无优惠、优惠折扣、优惠后金额中的一种。界面折数范围为 `0` 至 `10`，最多三位小数。`0 折` 表示应付为零，`10 折` 表示维持优惠前金额。界面折数乘 `10` 后传入 `discountRate`，例如 `9.5 折` 对应 `95.00`，`9.555 折` 对应 `95.55`。回显时将接口值除以 `10`，去除小数末尾无意义的零，显示「折」后缀。转换使用十进制并保留精度。服务端校验 `discountRate` 的 `0` 至 `100` 范围及最多两位小数。优惠后金额在 `0` 至该级优惠前金额之间，固定金额最多两位小数。空优惠保持原金额，两种优惠同时传入时拒绝请求。
4. 预览和保存共用服务端计算逻辑，用 `BigDecimal` 运算。数量和 SKU 单价保留各自精度。金额按下表执行 `HALF_UP` 舍入，先计算各行，再汇总，最后应用整单优惠。前端可实时展示输入反馈，预览与保存返回服务端计算结果。

| 金额 | 计算规则 |
| --- | --- |
| 行原价 | 当前选品售价或原报价行单价 × 数量，四舍五入至两位。 |
| 行成交额 | 无优惠时取行原价。折扣时取行原价 × 应付比例并四舍五入至两位。固定金额时取填写的优惠后金额。 |
| 整单优惠前金额 | 所有行成交额之和。 |
| 最终报价金额 | 对整单优惠前金额应用整单优惠，遵循同样的金额规则。 |
| 优惠金额 | 对应层级的优惠前金额减去优惠后金额，分别展示商品优惠与整单优惠。 |

以 CNY 为例，A 行 `129.345 × 2 = 258.69`，9 折后为 `232.82`。B 行 `80.00 × 1.50 = 120.00`，优惠后金额为 `100.00`。整单优惠前为 `332.82`，再按 9.5 折计算，**最终报价为 CNY 316.18**。整单优惠为 `16.64`。

### 预览、保存与版本变化

- 预览和保存对新选商品校验当前售价、币种、可用状态及商品和 SKU 的版本。版本不一致时提示刷新对应行，售价、币种、规格或数量精度变化时展示新值供用户确认。保留和复制的原报价行使用原快照的数量精度和原单价，原 SKU 后续改价、停用或删除仍可按原行计价。更改数量或优惠后重新计算行金额和总价。
- 客户版预览使用同一版式。新建草稿显示「未编号」，修改草稿的预览显示原正式单号。用户可以返回编辑、保存当前报价或另存为模板。关闭草稿会放弃本次编辑。
- 保存为模板时填写模板名称，并从报价表单提取报价标题、有序 SKU 明细及整单和行级的折扣与备注。相同 SKU 出现在多行时，逐行保存及恢复折扣和备注。模板保存仍校验当前 SKU 可用性，复制草稿中的失效 SKU 可移除或替换后再存模板。保存模板只写模板数据，报价草稿可继续编辑。

### 从已有报价新建

1. 在原报价的列表或详情点击「生成新报价」，弹窗提供「保留客户资料」与「清空客户资料」两个选项，取消则留在原页。复制已转单报价使用同一流程。
2. 保留选项带出原报价的标题、报价时间、开单方展示资料、客户资料、整单备注及有序商品行。每行带出原快照、单价、数量、行备注和优惠，整单优惠同时带出。清空选项只清除客户名称、联系人、联系电话和收货地址，其他报价字段照原单填入。
3. 复制接口读取原报价并返回草稿，前端用它打开新增报价页。用户可修改、预览或另存为个人或公共模板。点击「保存报价单」才创建新记录并取新单号，新单状态为「未生成订单」。

### 修改、删除和转单锁定

- 报价列表和详情显示「未生成订单」或「已生成订单」。未转单时，创建人具备对应权限即可修改或逻辑删除。编辑复用报价页，可修改标题、报价时间、客户资料、商品、备注和优惠。原单号、编号日期、流水、币种和开单方展示资料沿用原值。
- 修改或删除在事务中先锁定报价主表记录，再校验归属、逻辑删除标记、`order_generated` 和期望版本。修改按字段白名单更新主表与明细，移除的明细逻辑删除，重新计价后将版本加一。删除将主表标记为逻辑删除并递增版本，原单号保留。历史明细和快照随原记录保留，由主表状态控制业务可见性。
- 已生成订单时，后端拒绝修改、删除与修改预览，页面按状态隐藏修改和删除操作。后续订单服务按同样的主表行锁获取报价并校验版本，在创建订单的同一事务内将报价标记为已生成订单并递增版本。字段由服务端维护，本期报价接口只返回该状态。

## 3. 正式单号与保存事务

单号格式为 `QT-<年><MM><DD>-<三位流水>`。取号时读取一次系统时间并转换为 `Asia/Taipei` 日期。TWD 使用民国年，按公历年减 1911 计算，月和日各补至两位。CNY 使用四位公历年。以系统日期 2026-11-22 为例，当天第一张为 TWD 时生成 `QT-1151122-001`，第二张为 CNY 时生成 `QT-20261122-002`。即使业务报价时间填为 11 月 20 日，这两张的编号日期仍为 11 月 22 日。

### 新建保存顺序

1. Controller 校验报价表单的请求结构、字段格式和字段间约束，再调用 Service 创建报价。
2. 有复制来源时，先锁定来源报价，校验读取权限、未删除状态和来源版本，按提交的来源明细 ID 读取原快照和单价。新选商品按商品 ID 升序加锁，再按商品 ID、SKU ID 升序锁定 SKU，核验状态、版本、价格、币种与数量精度后获取快照。统一检查全单币种、计算金额，按表单顺序保存明细。修改已保存报价时沿用相同的商品锁顺序。
3. 进入取号步骤后确定编号日期。保存事务使用 `READ COMMITTED`，以报价模块和编号日期为锁键获取 PostgreSQL 事务级咨询锁（`pg_advisory_xact_lock`），让同一天的保存串行取号，覆盖当天还没有报价的情况。拿到锁后，在下一条语句从 `quotation` 按 `number_date` 查询 `MAX(daily_sequence)`。当天为空取 `001`，否则取最大值加一。当天最大值已为 `999` 时提示「今日正式报价单号已用完」。
4. 在同一事务中将编号日期、流水和正式单号写入报价主表，再保存明细，提交后才返回正式单号。事务结束自动释放当日锁。写入失败时，报价和本次新增的商品快照一同回滚，后续保存按已经提交的报价重新取号。事务确认回滚且数据库冲突可重试时，从事务入口整体重试并重新验证商品版本。

报价主表对 `quote_number`、`(number_date, daily_sequence)` 做唯一约束，并检查 `daily_sequence` 在 1～999 范围内。日期与流水的组合索引同时支持当日最大流水查询。取号查询包含历史和逻辑删除记录，确保已发单号持续有效。

## 4. 模板与权限

个人模板的列表、详情、修改和套用都按登录用户与模板所有者查找。公共模板列表需要公共模板查询权限，详情对已登录 ERP 用户开放。创建、修改和删除分别授权。具备公共模板修改权限的角色可编辑任意公共模板。套用个人模板需要个人模板查询和报价创建权限，套用公共模板需要报价创建权限。公共模板入口和个人模板入口以固定范围查询，访问另一范围的 ID 时与查无记录采用相同响应。

个人和公共模板都只允许创建人删除，并须具备对应范围的删除权限。后端在事务内按范围和归属锁定模板，校验期望版本后逻辑删除模板及其有效明细，并递增版本。非创建人、跨范围及重复删除按模板不存在处理。列表和详情返回 `ownedByCurrentUser`，前端结合对应权限展示删除入口。

### 实时校验和修复

- 列表、详情和套用都按当前商品和 SKU 批量检查可用性。列表返回可用状态及异常数量，详情返回已保存的两级折扣及受影响的 SKU、位置与原因，套用返回已保存的折扣、最新的选品数据与商品和 SKU 版本。
- 商品或 SKU 不存在、已逻辑删除、停用、缺少有效售价或售价币种，或者模板内的 SKU 售价币种分化，都会使模板不可套用。读取时保留失效明细的位置和 ID。删除或不存在的 SKU 须在模板中移除或替换。币种分化时展示各行的当前售价币种，便于修复。
- 创建和修改使用相同的模板表单，支持独立编辑模板名称和报价标题，也支持设置、调整或清空整单和行级的折扣与备注。报价标题必填，复用报价表单的标题校验。整单备注和每行备注可为空，各最多 1024 字符。折扣表单和详情统一按第 2 节的折数展示、范围校验和 `discountRate` 转换处理，空值表示未设置。修改时提交完整表单及 `expectedVersion`。服务端在同一事务更新主表与明细，校验至少有一行可用 SKU 且币种一致。版本冲突提示重新读取。暂时停用或缺少售价的 SKU 在恢复后按最新状态校验。
- 直接用模板初始化新报价时，填入模板的报价标题、商品行、两级优惠及整单备注。对进入替换确认的新增报价草稿，确认后替换报价标题、商品行及两级优惠，保留草稿的报价时间、客户资料和整单备注，包括原本为空的整单备注。两种入口均从模板填入行备注，空行备注保持为空。商品行数量初始化为 `1`，预览时按最新售价先算行折扣，再算整单折扣。

例如，同一 SKU 在模板中有两行，分别为 9 折、8 折，整单为 9.5 折。SKU 售价更新至 `120.00` 后，每行按默认数量 `1` 计算，行成交额为 `108.00` 和 `96.00`，最终报价金额为 `193.80`。

## 5. 数据和接口

### PostgreSQL 数据表

| 表 | 关键字段与约束 |
| --- | --- |
| `quotation` | `quote_number`、`number_date`、`daily_sequence`、`owner_user_id`、`title`、`quoted_at`、`currency`、`order_generated`、`version`、客户名称及联系方式、收货地址、备注、开单方展示资料、行原价合计、行成交额合计、整单优惠及最终金额。按创建人、报价时间和 ID 建立列表索引。 |
| `quotation_item` | `quotation_id`、`snapshot_id`、`currency`、`quantity`、`unit_price`、行原价、优惠参数、行成交额、备注、`sort_order`。按报价 ID 与顺序读取，按快照 ID 支持历史引用查询。来源 SKU 通过快照追溯。 |
| `quotation_template` | `name`（模板名称）、`title`（必填的报价标题）、`scope`、`owner_user_id`、`version`、可空的 `discount_rate`（整单折扣）与 `remark`（整单备注）。公共模板保留创建者供维护审计。按范围及更新时间分页，个人查询增加归属条件。 |
| `quotation_template_item` | `template_id`、`sku_id`、`sort_order`、可空的 `discount_rate`（行折扣）与 `remark`（行备注）。有效明细的 `(template_id, sort_order)` 唯一，同一 SKU 可出现在多个位置。SKU 采用逻辑关联，商品删除后模板可定位并修复旧条目。 |

业务表沿用项目标准主键、审计字段和逻辑删除规则。编号日期按 `date` 保存，手填报价时间使用 `timestamp with time zone`。报价转单状态使用 `order_generated boolean DEFAULT false NOT NULL`，报价版本使用 `version bigint DEFAULT 0 NOT NULL` 并约束版本非负。数量、原始单价和各金额字段统一使用 `numeric(20,6)`。Service 在写入前校验计价结果是否超出存储范围。模板折扣使用 `numeric(5,2)`，两张模板表分别约束 `discount_rate` 在 0～100。数据库约束覆盖正数数量、合法币种、范围、优惠字段互斥和金额非负。数量精度、跨行币种一致及模板可用性由 Service 校验。

客户字段直接使用 `QuotationVO` 的平铺属性，对应 `shipping_address`、`customer_name`、`contact_name` 和 `contact_phone`，按本单文本保存。数据库预留可空的联系人电子邮件字段 `contact_email`，旧库升级时保留已有值。当前表单、详情、复制和客户版沿用上述四项客户资料。开单方名称和联系信息从部署配置读取，首次新建时固化，复制报价时沿用原报价的名称和联系信息。客户版直接使用当前部署配置中的 Logo。

权限码以下表为准。报价选品使用独立入口复用商品查询，避免授予业务人员商品管理权限。模板各行的 `{scope}` 代表明确注册的两个前缀 `/quotation/template/personal`、`/quotation/template/public`。Controller 分别注册两组路径，范围由入口决定。

| 方法与路径 | 请求及响应 | 权限 |
| --- | --- | --- |
| GET `/quotation/sku/options` | 按关键字、类目、规格及可选 `referenceSaleCurrency` 分页，返回 `ProductOptionVO`。 | `sales-manager:quotation:create` 或 `sales-manager:quotation:update` |
| POST `/quotation/preview` | 接收平铺的 `QuotationVO`，返回同模型的新建或复制草稿预览。 | `sales-manager:quotation:create`，引用来源时额外校验来源读取资格 |
| POST `/quotation/create` | 接收同一 `QuotationVO`，返回包含正式 ID、单号和明细的完整报价。 | `sales-manager:quotation:create`，引用来源时额外校验来源读取资格 |
| GET `/quotation/list` | 使用 `QuotationVO` 筛选字段，分页返回平铺主表，不返回明细。 | `sales-manager:quotation:query` 且为创建人 |
| GET `/quotation/detail?id=…` | 返回主表字段及 `items`，明细直接包含商品资料和图片。 | `sales-manager:quotation:query` 且为创建人 |
| POST `/quotation/update/preview` | 接收包含 `id`、`version` 和完整内容的 `QuotationVO`，返回同模型的修改预览。 | `sales-manager:quotation:update` 且为创建人，报价未生成订单 |
| POST `/quotation/update` | 接收同一 `QuotationVO`，保存并返回平铺的完整报价。 | `sales-manager:quotation:update` 且为创建人，报价未生成订单 |
| POST `/quotation/delete` | 复用 `QuotationVO`，只提交 `id` 和 `version`，逻辑删除报价。 | `sales-manager:quotation:delete` 且为创建人，报价未生成订单 |
| POST `/quotation/copy` | 复用 `QuotationVO`，提交 `id` 和必填 `clearCustomer`，返回带 `sourceId`、`sourceVersion` 的平铺草稿。 | `sales-manager:quotation:query` 和 `sales-manager:quotation:create`，且为原报价创建人 |
| GET `/quotation/template/{scope}/list`、`/detail` | 列表和详情共用 `QuotationTemplateVO`，详情额外返回两级折扣、备注和实时问题明细。 | 个人需要 `sales-manager:quotation-template:personal:query` 且为所有者。公共列表需要 `sales-manager:quotation-template:public:query`，公共详情需要登录。 |
| POST `/quotation/template/{scope}/create` | `QuotationTemplateVO` 提交模板名称 `name`、报价标题 `title`、可选的整单 `discountRate` 和 `remark`，以及有序明细。每行包含 `skuId`、可选的 `discountRate` 和 `remark`。 | `sales-manager:quotation-template:personal:create` 或 `sales-manager:quotation-template:public:create`，按入口对应。 |
| POST `/quotation/template/{scope}/update` | 复用模板表单，提交 ID、期望版本及完整内容。 | 对应范围的 `sales-manager:quotation-template:personal:update` 或 `sales-manager:quotation-template:public:update`，个人另校验归属。 |
| POST `/quotation/template/{scope}/delete` | 复用 `QuotationTemplateVO`，提交 `id` 和 `version`，成功返回 `JsonResult<Void>`。 | 对应范围的模板删除权限，且为模板创建人。 |
| POST `/quotation/template/{scope}/apply` | 请求复用 `QuotationTemplateVO`，只提交模板 ID；返回可直接预览或保存的 `QuotationVO`，明细为当前选品及默认数量。 | 两类都需要 `sales-manager:quotation:create`，个人另需个人模板查询权限和归属校验。 |

- 模块只保留对应四张表的 `QuotationVO`、`QuotationItemVO`、`QuotationTemplateVO`、`QuotationTemplateItemVO`，均继承实体，按接口校验和写入白名单复用。客户、开单方、折扣和金额使用平铺字段，明细与商品资料只返回一份。
- 报价更新和删除提交 `id`、`version`；复制来源为 `sourceId`、`sourceVersion`。沿用历史行提交明细 `id`，服务端验证归属并使用原快照、币种和单价；新选行无 `id`，提交 `skuId`、`productVersion` 和 `skuVersion`。两级优惠直接使用 `discountRate`、`discountedAmount`，不再包装优惠对象。
- 预览、详情、创建、更新和复制共用 `QuotationVO`。预览返回的数据可以直接保存，复制预览保留来源信息。新报价主键、单号、价格、审计字段和转单状态由服务端维护。客户资料以后续草稿中的值为准。金额和数量按默认 JSON 数值传输，业务时间带偏移，长整型 ID 精确传输。
- 后端新增 `quotation` 模块。Controller 负责结构、格式及字段间校验，Service 负责业务校验、访问范围、计价和事务，Mapper 负责批量查询、获取当日取号锁和查询主表最大流水。按项目使用 `JsonResult<T>`、`pageNum` 和 `pageSize`、`BeanConvertUtils`，将模块错误加入 `i18n/quotation/messages*.properties`，公共分页错误复用已有资源。

## 6. 客户版报价单

客户版采用可滚动的单张长页。预览、历史客户版和截图共用正文。草稿使用服务端预览结果，历史报价使用已保存的快照结果。前端在共用的 `QuotationPaper` 组件取消 A4 固定高度、分页测量、续页页眉和页脚。报价识别区在顶部出现一次，整单备注和金额汇总位于最后一条商品之后。参见 [客户版长页设计稿](prototypes/quotation-customer-long.html)。

- 白底正文搭配深蓝标题区和表头、浅灰蓝分隔线，暖金强调报价总额。标题区展示报价标题、开单方名称、配置中的 Logo 和联系方式，右侧对齐单号与报价时间。标题和备注按普通文本输出，整单及行备注在编辑页标注「客户版可见」。
- 「客户信息」按客户名称、联系人、联系电话、收货地址排列，依次绑定 `customerName`、`contactName`、`contactPhone`、`shippingAddress`。空字段自动收起。长地址随列宽换行。
- 商品明细按「序号」「商品」「单价」「数量」「优惠」「金额」「备注」排列。商品列左侧显示主图缩略图，右侧第一行是商品名称，第二行是 SKU 编码。规格从第三行起按顺序两项一行，奇数项最后一项靠左，长名称和长规格可换行。型号随规格以同样格式展示。无图或加载失败时由文字占满该列。数量同行展示单位。金额列右对齐并使用等宽数字，首行展示 `lineAmount`，有实际行优惠时展示次行原价。单价下方展示币种编码，合计区按需展示两级优惠，报价总额使用 `totalAmount`。设置整单折扣时在汇总的整单优惠行附上折数。
- 商品图片读取 `items[].images`，复用商品模块的图片视图和授权 URL。新选行读取当前 SKU 图片，历史行批量读取快照图片，包含来源、主图标记和顺序；无图返回空列表。
- 接入两列规格时，报价明细补充有序的 `items[].specs`，复用 `ProductOptionSpecVO` 的规格名称、值和单位。新选行取当前选品规格，沿用快照和历史行取冻结规格。同名型号规格只展示一次，无规格时收起规格区。旧接口仅提供 `specificationText` 时，可在 SKU 编码下显示原摘要，待结构化规格可用后按项排列。
- 行备注绑定 `items[].remark` 并保留原换行。报价预览和历史查看默认最多显示两行，按当前列宽检测溢出。发生省略时在备注右下方显示「展开」，点开后显示该行全文，按钮切换为「收起」。短备注直接显示，空备注显示 `—`。前端复用 `QuotationPaper` 的 `Typography.Paragraph` 省略交互。截图视图显示完整备注并隐藏展开和收起按钮。
- 标题、规格、地址及备注随内容增高。宽屏展示七列表格，窄屏逐条展示带字段标签的商品明细，沿用同样的阅读顺序。截图视图沿用当前宽度下的正文布局，导航和操作置于正文范围外。
- 视觉验收使用少量与多商品样例，覆盖简中、繁中、CNY、TWD、长地址、多行备注、缺省字段及零价行。客户版仅请求已登录且有权访问的报价数据。涉及客户资料的预览和详情响应禁止缓存，截图页不展示进价、库存、审计或 SKU 内部 ID。

前端联调由前端项目实施。普通新增、套用模板、从旧报价新建和修改共用报价编辑页，按入口选择预览和保存接口。报价列表与详情按权限及转单状态展示操作，复制入口使用客户资料选择弹窗。继续沿用同币种选品、动态数量精度、两级优惠、模板修复及独立的客户版截图视图。

## 8. 报价 UI 原型与实施验收

### 8.1 原型与交互约定

以 [报价管理交互原型 V14（独立桌面版）](prototypes/quotation-desktop.html) 为业务主体的视觉基准。第 1～6 节定义业务、接口和客户版规则。原型使用会话内示例数据，重新载入后恢复样例。原型中的「商品变动」只用于复现版本冲突。

- ERP 左侧菜单的「报价管理」分组放置「报价单列表」和「报价模板」入口。通过「报价模板」进入时，默认选中「个人模板」页签，可切换至「公共模板」页签。从模板详情返回时回到该模板所属页签。业务页标题区保留路径与页面操作。列表、详情、编辑和模板页高亮所属菜单项，客户版预览和截图使用独立布局。报价列表按标题、单号、客户名称、日期和转单状态筛选，显示币种、金额和转单状态。详情、修改、生成新报价和删除在桌面列表直接展示。详情始终提供返回和查看客户版入口，按创建人、权限及转单状态决定可见动作。删除先确认，失败时保留当前详情或列表。生成新报价先选保留或清空客户资料，取消弹窗回到发起页。
- 四种入口共用报价编辑页。左侧依次放报价信息、客户资料和商品明细。客户资料依次排列客户名称、联系人、联系电话和收货地址，收货地址使用标准单行输入框。桌面为同一行，中等宽度分两行。详情沿用客户资料字段名称和顺序，长地址文本可换行。商品明细每条 SKU 明细占一行，列序依次为「序号」「商品/SKU」「单价」「数量」「优惠」「金额」「备注」「操作」。备注直接在对应行填写。编辑页、详情和客户版统一使用「单价」「优惠」「金额」，其中「金额」展示行成交额。桌面右侧依次放报价汇总和常驻的整单备注输入框，宽度不足时右栏排到正文之后。备注输入即时保留在草稿中，预览和保存时一起提交。预览与保存放在页首右侧。包含未保存修改时，点击左侧菜单或取消均先确认是否放弃。普通新增、复制和套用可另存为模板。
- 报价详情的商品明细沿用编辑页前七列，按「序号」「商品/SKU」「单价」「数量」「优惠」「金额」「备注」排列。数量、优惠和备注以只读文本呈现，备注放在对应商品行，保留原换行，空备注显示 `—`。
- 选品弹窗支持搜索、类目、规格和币种筛选。新增使用复选，替换使用单选。新草稿首次选品时，可选任一币种。已选首个 SKU 后，本次选择中的其他币种禁选。确认添加后，后续查询按本单币种过滤。已有报价固定原币种。重复 SKU 可分次加入并各自保存数量、折扣和备注。只读单价旁标注币种，数量框旁标注单位和允许的小数精度。新选商品版本冲突时，在失败提示与对应行提供刷新入口，经对比确认后更新该行。无法继续使用时，明确提示移除或替换。
- 行级与整单各用一个优惠方式下拉切换「无优惠」「优惠折扣」「优惠后金额」。折扣输入带「折」后缀，优惠后金额输入带币种符号前缀。折扣输入提示示例为 `9.5`，报价详情、模板和客户版按「9.5 折」展示。校验错误显示在对应输入或行下。修改数量或优惠时更新行成交额和汇总，预览和保存采用第 2 节约定的服务端结果。空明细和错误状态可继续编辑，提交时说明阻塞原因。
- 金额统一在数字前展示币种符号，CNY 用 `¥`，TWD 用 `NT$`。列表报价总额、选品单价、编辑页、详情和客户版的单价在金额下方显示币种编码。编辑页、详情和客户版的商品明细「金额」列首行以粗体显示行成交额，例如 `¥ 1,080.00`。有实际行优惠时，次行以辅助文字显示 `原价 ¥ 1,200.00`。编辑页和详情的成交额和原价各自保持单行、右对齐，客户版金额随可用宽度换行。详情和客户版使用 `items` 的 `lineAmount` 和 `originalAmount`。详情和编辑页右侧汇总、客户版合计及其他紧凑位置采用单行符号金额。零金额带符号，缺失金额显示 `—`。
- 新增报价需要确认替换时，从模板选择弹窗切换为独立确认弹窗，背景为当前报价编辑页。标题为「替换报价内容」，正文为「套用后将替换报价标题、商品行及两级优惠。报价时间、客户资料和整单备注会保留。」底栏右侧依次为「取消」和主按钮「确认套用」。右上角提供关闭按钮。取消或关闭后返回编辑页，草稿保持原样。确认后应用模板并保留正文所列字段。
- 模板列表将可用性与异常数量放在同一列，模板详情展示所属范围和整单备注，逐行展示当前售价币种、行备注及异常原因。异常模板禁用套用，维护者可进入共用模板表单替换或移除异常行。保存模板保留报价标题、行顺序、折扣和备注，空折扣和空备注保持空值，报价草稿及单号保持当前状态。
- 客户版工具栏位于长页正文之外。新增预览显示「未编号」，修改预览及历史客户版显示正式单号。历史客户版返回详情，草稿预览返回编辑。截图视图收起预览工具栏，退出按钮保留在正文外。客户版以第 6 节长页设计稿为视觉基准。

### 8.2 主题与桌面尺寸

### 8.3 联调与验收用例

1. 使用同一浏览器、视口和缩放逐屏对照原型和真实页面。至少检查左侧菜单选中态与离开草稿确认、报价列表、未转单和已转单详情、新建及有数据的编辑页、选品、复制确认、报价模板默认页签及切换、从模板详情返回所属页签、异常模板修复、客户版预览与截图。提供相同状态的对照截图。
2. 用浏览器盒模型测量搜索、日期、数量、金额、下拉框外框及圆角，核对表头、金额列右边缘、正文与汇总的顶部对齐、两类弹窗宽度以及客户版最大宽度。固定尺寸与对齐的取整偏差最多 `1` CSS px。核对窄屏时表单换行、业务表格的局部滚动和客户版商品明细重排。
3. 用「展厅储物设备报价」核对 9.5 折对应 `¥ 316.18`、数量尾零、优惠方式切换、桌面客户资料同排等宽等高且收货地址在最右。核对编辑、详情和客户版的商品明细列序、独立备注列，以及金额 `¥ 232.82` 与次行 `原价 ¥ 258.69`。无行优惠时只显示成交额。新建时将单价 `¥ 120.00` 的商品数量调为 `10`、优惠设为 `9 折`，确认 `¥ 1,080.00` 和 `原价 ¥ 1,200.00` 各占一行。验证备注可填写、清空并在客户版预览，修改沿用单号。用「展櫃與導軌配置報價」核对繁中、TWD、多商品长页、长地址、零价、行备注、转单锁定及复制客户资料的两种选择。两个样例均核对列表总额的双行币种展示、右侧汇总和客户版合计的单行符号格式，以及优惠后金额输入的前缀。
4. 套用个人模板「门店陈列 · 常用组合」，核对两条相同 SKU、行折扣、整单折扣和 CNY `193.80`。在已有标题、商品行、客户资料和整单备注的新增草稿上再次套用，核对「替换报价内容」弹窗的标题、正文和按钮。取消和关闭均返回原草稿。确认后核对报价时间、客户资料和整单备注保留，报价标题、商品行和两级优惠已替换。打开「开业物料 · 待修复」，核对异常位置、停用、删除和币种不一致。修复后检查套用恢复，并验证模板名称与报价标题独立保存。
5. 使用第 5 节接口和第 7 节业务用例联调。重点验证读取与写入权限、服务端金额与版本校验、保存后才取号、正式单号与报价时间独立、历史快照、失败保留草稿，以及客户版响应的访问控制和缓存设置。
6. 核对宽屏和窄屏的商品主图、无图及图片加载失败的布局。检查商品名称、SKU 编码和规格的顺序，用零项、三项、四项和长规格验证两列布局。保存报价后修改商品主图及规格，确认历史报价和沿用快照的商品行继续显示冻结资料。检查短备注、恰好两行和超长备注，只有实际发生省略时出现「展开」。打开和收起时只影响对应行，截图视图显示全文。
